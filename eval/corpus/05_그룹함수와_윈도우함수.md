# 그룹 함수와 윈도우 함수

## ROLLUP, CUBE, GROUPING SETS
ROLLUP은 GROUP BY에 지정한 컬럼 순서대로 계층별 소계와 전체 합계를 구한다. ROLLUP(A, B)는 (A, B)별 소계, A별 소계, 전체 합계를 만든다. 인수의 순서가 바뀌면 결과가 달라진다.
CUBE는 지정한 컬럼의 모든 조합에 대해 소계를 구한다. CUBE(A, B)는 (A, B), A, B, 전체 합계를 모두 만든다. 다차원 집계를 하므로 연산량이 많다.
GROUPING SETS는 원하는 그룹 조합만 골라 집계하며, 인수의 순서가 바뀌어도 결과는 같다. GROUPING SETS(A, B)는 A별 소계와 B별 소계만 구하고 전체 합계는 만들지 않는다.
GROUPING 함수는 해당 컬럼이 집계(소계)에 의해 생성된 행이면 1을, 아니면 0을 반환한다. CASE 문과 함께 써서 소계 행에 '전체 합계' 같은 문자열을 표시할 때 쓴다.

## 윈도우 함수
윈도우 함수는 행과 행 사이의 관계를 정의하거나 비교, 연산하는 함수로, 분석 함수라고도 한다. 기본 문법은 함수명(인수) OVER (PARTITION BY 컬럼 ORDER BY 컬럼 WINDOWING 절) 형태다. 윈도우 함수를 사용해도 결과 행의 수는 줄어들지 않는다.

## 순위 함수
RANK는 동일한 값에 같은 순위를 부여하고, 그다음 순위는 동일 순위의 개수만큼 건너뛴다. 예를 들어 1위가 두 명이면 다음 순위는 3위다.
DENSE_RANK는 동일한 값에 같은 순위를 부여하지만 다음 순위를 건너뛰지 않는다. 1위가 두 명이면 다음 순위는 2위다.
ROW_NUMBER는 동일한 값이어도 고유한 순위를 부여한다. 1, 2, 3처럼 중복 없는 번호가 매겨진다.

## 집계 윈도우 함수
SUM, MAX, MIN, AVG, COUNT 같은 집계 함수도 OVER 절과 함께 쓰면 윈도우 함수가 된다. PARTITION BY로 그룹을 나누고 ORDER BY를 지정하면 누적 합계를 구할 수 있다.

## 행 순서 함수
FIRST_VALUE는 파티션별 윈도우에서 가장 먼저 나온 값을, LAST_VALUE는 가장 나중에 나온 값을 구한다.
LAG는 파티션별 윈도우에서 이전 몇 번째 행의 값을 가져오고, LEAD는 이후 몇 번째 행의 값을 가져온다. 전월 대비 매출 증감처럼 앞뒤 행과 비교할 때 쓴다.

## 비율 함수
RATIO_TO_REPORT는 파티션 내 전체 SUM 값에 대한 행별 컬럼 값의 백분율을 소수점으로 구한다.
PERCENT_RANK는 파티션에서 제일 먼저 나오는 것을 0, 제일 늦게 나오는 것을 1로 하여 행의 순서별 백분율을 구한다.
CUME_DIST는 파티션 전체 건수에서 현재 행보다 작거나 같은 건수에 대한 누적 백분율을 구한다.
NTILE은 파티션별 전체 건수를 인수 값으로 N등분한 결과를 구한다. 예를 들어 NTILE(4)는 행을 4개 그룹으로 나눈다.

## WINDOWING 절
WINDOWING 절은 함수의 대상이 되는 행의 범위를 지정한다. ROWS는 물리적인 행 단위로, RANGE는 논리적인 값의 범위로 지정한다.
UNBOUNDED PRECEDING은 윈도우의 시작 위치가 파티션의 첫 번째 행임을, UNBOUNDED FOLLOWING은 끝 위치가 파티션의 마지막 행임을, CURRENT ROW는 현재 행을 의미한다.
ORDER BY만 지정하고 WINDOWING 절을 생략하면 기본 범위는 RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW가 된다. 그래서 LAST_VALUE를 그냥 쓰면 현재 행까지의 마지막 값, 즉 현재 행의 값이 나오는 경우가 많다.

## TOP N 쿼리
Oracle의 ROWNUM은 쿼리 결과에 붙는 가상 컬럼으로, 조건절에서 ROWNUM <= N 형태로 상위 N개 행을 가져올 때 사용한다. ROWNUM은 ORDER BY보다 먼저 부여되므로, 정렬 후 상위 N개를 가져오려면 인라인 뷰에서 정렬한 뒤 바깥에서 ROWNUM 조건을 걸어야 한다. ROWNUM = 2처럼 1이 아닌 값과 같다는 조건은 결과가 나오지 않는다.
SQL Server에서는 TOP(N)을 사용하며, WITH TIES 옵션을 함께 쓰면 마지막 순위와 같은 값을 가진 행도 함께 출력한다.
