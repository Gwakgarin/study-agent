# 운영체제

## 프로세스와 스레드
프로세스는 실행 중인 프로그램으로, 운영체제로부터 자신만의 독립된 메모리 공간(코드, 데이터, 힙, 스택)을 할당받는다.
스레드는 프로세스 안에서 실행되는 흐름의 단위로, 같은 프로세스의 스레드들은 코드, 데이터, 힙 영역을 공유하고 스택만 따로 가진다. 그래서 스레드 사이의 문맥 교환은 프로세스 사이보다 가볍다.
PCB(프로세스 제어 블록)는 운영체제가 프로세스를 관리하기 위해 프로세스 상태, 프로그램 카운터, 레지스터 값, 메모리 정보 등을 저장한 자료 구조다.

## 프로세스 상태
프로세스는 생성, 준비, 실행, 대기(블록), 종료 상태를 거친다.
준비 상태의 프로세스가 CPU를 할당받아 실행 상태가 되는 것을 디스패치라고 한다.
실행 중인 프로세스가 할당된 시간을 다 쓰면 타이머 런아웃으로 다시 준비 상태가 된다.
실행 중인 프로세스가 입출력을 기다리면 대기 상태가 되고, 입출력이 끝나면 웨이크업으로 준비 상태로 돌아간다.

## CPU 스케줄링
선점형 스케줄링은 실행 중인 프로세스에게서 CPU를 강제로 빼앗을 수 있는 방식이고, 비선점형 스케줄링은 프로세스가 CPU를 스스로 반납할 때까지 빼앗지 않는 방식이다.
FCFS(FIFO)는 먼저 도착한 프로세스부터 처리하는 비선점형 방식이다.
SJF는 실행 시간이 가장 짧은 프로세스부터 처리하는 비선점형 방식으로 평균 대기 시간이 가장 짧지만, 실행 시간이 긴 프로세스가 계속 밀리는 기아 현상이 생길 수 있다.
HRN은 SJF의 기아 현상을 보완한 비선점형 방식으로, 우선순위를 (대기 시간 + 서비스 시간) / 서비스 시간 으로 계산해 값이 큰 프로세스부터 처리한다.
라운드 로빈(RR)은 각 프로세스에 같은 크기의 시간 할당량(타임 슬라이스)을 주고 돌아가며 실행하는 선점형 방식이다. 할당량이 너무 크면 FCFS와 비슷해지고, 너무 작으면 문맥 교환이 잦아진다.
SRT는 SJF의 선점형 버전으로, 남은 실행 시간이 더 짧은 프로세스가 도착하면 CPU를 넘긴다.
에이징은 오래 기다린 프로세스의 우선순위를 점점 높여 기아 현상을 막는 기법이다.

## 교착상태
교착상태(데드락)는 둘 이상의 프로세스가 서로 상대가 가진 자원을 기다리며 무한히 멈춰 있는 상태다.
교착상태는 상호 배제, 점유와 대기, 비선점, 환형 대기 네 가지 조건이 모두 성립할 때 발생한다.
예방은 네 가지 조건 중 하나를 원천적으로 막는 방법이다. 회피는 자원을 할당하기 전에 안전 상태인지 검사해 교착상태가 생길 수 있는 할당을 피하는 방법으로, 대표적인 것이 은행원 알고리즘이다. 발견은 교착상태가 생겼는지 주기적으로 검사하는 것이고, 회복은 교착상태에 빠진 프로세스를 종료하거나 자원을 빼앗아 해결하는 것이다.

## 가상 메모리와 페이지 교체
가상 메모리는 보조기억장치의 일부를 주기억장치처럼 사용해, 실제 메모리보다 큰 프로그램을 실행할 수 있게 하는 기법이다. 페이징 기법은 프로그램을 같은 크기의 페이지로, 세그먼테이션 기법은 논리적 단위인 서로 다른 크기의 세그먼트로 나눈다.
페이지 부재(페이지 폴트)는 참조하려는 페이지가 주기억장치에 없는 경우다. 이때 빈 프레임이 없으면 페이지 교체 알고리즘으로 내보낼 페이지를 고른다.
FIFO는 가장 먼저 들어온 페이지를 교체한다. 프레임 수를 늘렸는데 오히려 페이지 부재가 늘어나는 벨레이디의 모순이 생길 수 있다.
LRU는 가장 오랫동안 사용되지 않은 페이지를 교체한다. LFU는 사용 횟수가 가장 적은 페이지를 교체한다.
OPT(최적 교체)는 앞으로 가장 오랫동안 사용되지 않을 페이지를 교체하는 방식으로, 페이지 부재가 가장 적지만 미래를 알아야 해서 실제로 구현하기 어렵다.
스래싱은 페이지 교체가 너무 자주 일어나서 프로세스가 실제 작업보다 페이지 교체에 더 많은 시간을 쓰는 현상이다. 워킹 셋은 프로세스가 일정 시간 동안 자주 참조하는 페이지들의 집합으로, 이를 메모리에 유지하면 스래싱을 줄일 수 있다.
지역성(구역성)은 프로세스가 실행되는 동안 일부 페이지만 집중적으로 참조하는 성질로, 시간 지역성과 공간 지역성이 있다.
